# 🎛️ Админ-панель DOBRO - Руководство

## Доступ к админ-панели

### Через Telegram бота
Для администраторов доступны дополнительные команды:

```
/admin - Админ-панель
/stats_all - Общая статистика
/users - Список пользователей
/guides_all - Все гайды
```

### Через Web интерфейс
URL: `https://your-domain.com/admin`

Логин: admin@dobro.app  
Пароль: (установить в .env)

---

## Функции админ-панели

### 1. Статистика системы
- Общее количество пользователей
- Количество созданных гайдов
- Активность по дням/неделям
- Популярные темы
- Конверсия (регистрация → создание гайда)

### 2. Управление пользователями
- Просмотр списка пользователей
- Поиск по email/имени
- Изменение подписки
- Блокировка/разблокировка
- Просмотр активности

### 3. Управление гайдами
- Просмотр всех гайдов
- Модерация контента
- Удаление неподходящих гайдов
- Экспорт статистики

### 4. Настройки системы
- Лимиты для Free плана
- Цены подписок
- Настройки AI (модель, температура)
- Email уведомления
- Telegram уведомления

## Временное решение

### Получить статистику
```bash
curl -H "Authorization: Bearer ADMIN_TOKEN" \
  https://your-domain.com/api/admin/stats
```

### Список пользователей
```bash
curl -H "Authorization: Bearer ADMIN_TOKEN" \
  https://your-domain.com/api/admin/users
```

### Список гайдов
```bash
curl -H "Authorization: Bearer ADMIN_TOKEN" \
  https://your-domain.com/api/admin/guides
```
