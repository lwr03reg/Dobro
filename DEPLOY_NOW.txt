Проблема: Build failed
→ Проверьте логи деплоя
→ Убедитесь, что Root Directory = backend
→ Проверьте, что все переменные добавлены

Проблема: Database connection error
→ Проверьте DATABASE_URL в Variables
→ Убедитесь, что PostgreSQL сервис запущен

Проблема: 500 Internal Server Error
→ Проверьте логи сервиса
→ Убедитесь, что GEMINI_API_KEY валидный
→ Проверьте, что миграции применились
