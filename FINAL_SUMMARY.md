## 🎬 КАК ИСПОЛЬЗОВАТЬ

### Для пользователей

1. Откройте терминал
2. Перейдите в папку: `cd Dobro`
3. Запустите: `./start.sh`
4. Откройте браузер: http://localhost:3000

### Для разработчиков

```bash
# Запуск
./start.sh

# Проверка статуса
./status.sh

# Просмотр логов
tail -f logs/backend.log logs/frontend.log

# Диагностика
./healthcheck.sh

# Остановка
./stop.sh

# Перезапуск
./restart.sh
```

### Для деплоя

```bash
# Railway (облако)
# Следуйте RAILWAY_DEPLOY.md

# Docker (локально)
./docker-start.sh

# Production
NODE_ENV=production ./start.sh
```
