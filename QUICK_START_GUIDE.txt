│                                                                             │
│ Скачай проект на свой компьютер:                                           │
│                                                                             │

│   cd Dobro                                                                  │
│   ./quick-start.sh                                                          │
│                                                                             │
│ Требования:                                                                 │
│   • Docker Desktop                                                          │
│   • Node.js 20+                                                             │
│   • OpenAI API key                                                          │
│                                                                             │
│ Время: 5-10 минут                                                           │
│ Стоимость: 0₽                                                               │

┌─────────────────────────────────────────────────────────────────────────────┐
│ ВАРИАНТ 2: Rebuild Gitpod devcontainer                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ Установи Node.js и Docker в Gitpod:                                        │
│                                                                             │
│   1. Devcontainer уже обновлён (.devcontainer/devcontainer.json)           │
│   2. Нажми Ctrl+Shift+P                                                     │
│   3. Выбери "Dev Containers: Rebuild Container"                            │
│   4. Подожди 5-10 минут                                                     │
│   5. После rebuild: ./quick-start.sh                                        │
│                                                                             │
│ Время: 10-15 минут (rebuild)                                                │
│ Стоимость: 0₽                                                               │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ВАРИАНТ 3: Deploy на Railway.app (бесплатно)                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ Запусти в облаке за 5 минут:                                               │
│                                                                             │
│   1. Зарегистрируйся: https://railway.app                                  │
│   2. Подключи GitHub репозиторий                                            │
│   3. Railway автоматически определит Dockerfile                             │
│   4. Добавь environment variables:                                          │
│      • OPENAI_API_KEY=sk-proj-...                                           │
│      • JWT_SECRET=your-secret                                               │
│   5. Deploy!                                                                │
│                                                                             │
│ Время: 5 минут                                                              │
│ Стоимость: 0₽ (первые $5 бесплатно)                                        │
└─────────────────────────────────────────────────────────────────────────────┘
