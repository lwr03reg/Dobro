┌──────────────────────────────────────────────────────────────┐
│ ШАГ 1: Создать бота (5 минут)                               │
└──────────────────────────────────────────────────────────────┘

1. Открыть @BotFather в Telegram
2. Отправить: /newbot
3. Имя бота: DOBRO Guide Creator
4. Username: dobro_guide_bot (или любой доступный)
5. Скопировать токен (формат: 1234567890:ABCdefGHI...)

┌──────────────────────────────────────────────────────────────┐
│ ШАГ 2: Настроить команды (1 минута)                         │
└──────────────────────────────────────────────────────────────┘

Отправить @BotFather:

/setcommands
@dobro_guide_bot

start - 🚀 Начать работу с ботом
new - ✨ Создать новый гайд
list - 📚 Мои гайды
trending - 🔥 Трендовые темы
settings - ⚙️ Настройки
help - ❓ Помощь

┌──────────────────────────────────────────────────────────────┐
│ ШАГ 3: Добавить токен (30 секунд)                           │
└──────────────────────────────────────────────────────────────┘

nano .env

# Найти строку:
TELEGRAM_BOT_TOKEN=

# Вставить токен:
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather

# Сохранить: Ctrl+O, Enter, Ctrl+X

┌──────────────────────────────────────────────────────────────┐
│ ШАГ 4: Перезапустить backend (30 секунд)                    │
└──────────────────────────────────────────────────────────────┘

pkill -f "tsx.*src/index.ts"
cd backend && npm run dev

# Должно появиться:
# ✅ Telegram bot initialized successfully
# 🚀 DOBRO Backend started on port 3001

│ ШАГ 5: Открыть бота (30 секунд)                             │
└──────────────────────────────────────────────────────────────┘

1. Найти @dobro_guide_bot в Telegram
2. Нажать Start
3. Увидеть приветствие
4. Начать создавать гайды! ✨
