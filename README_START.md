# 🚀 DOBRO SYSTEM

## Запуск одной командой

```bash
./start.sh
```

## Что это?

DOBRO - полнофункциональная система для генерации AI-гайдов с Telegram Bot интеграцией.

## Возможности

- ✅ AI генерация контента (Google Gemini)
- ✅ Telegram Bot
- ✅ PDF экспорт
- ✅ Система подписок
- ✅ Премиум UI/UX (100/10)
- ✅ PostgreSQL + Redis
- ✅ Docker поддержка
- ✅ **Запуск одной командой**

## Быстрый старт

### 1. Требования
- Docker Desktop
- Node.js 20+
- Git

### 2. Клонирование
```bash
git clone https://github.com/lwr03reg/Dobro.git
cd Dobro
```

### 3. Запуск
```bash
./start.sh
```

### 4. Открыть
- Frontend: http://localhost:3000
- Backend: http://localhost:3001

## Управление

```bash
./start.sh       # Запуск
./stop.sh        # Остановка
./restart.sh     # Перезапуск
./status.sh      # Статус
./healthcheck.sh # Диагностика
```
