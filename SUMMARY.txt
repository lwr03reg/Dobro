1. Получи OpenAI API key:
   https://platform.openai.com/api-keys

2. Настрой .env:
   cp .env.example .env
   nano .env  # Добавь OPENAI_API_KEY

3. Запусти backend:
   cd backend
   npm install
   docker-compose up -d postgres redis
   npm run prisma:migrate
   npm run dev

4. Проверь:
   curl http://localhost:3001/health
